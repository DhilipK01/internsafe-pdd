# INTERNSAFE AI brand assets

**Official logo (use everywhere):** `assets/branding/internsafe_ai_logo.png`

In Dart, always reference via `BrandAssets.logo` from `lib/core/constants/brand_assets.dart`.

Do not add SVG placeholders or alternate shield icons.

Web/API static copy: `api/static/brand/internsafe_ai_logo.png` (served at `/brand/internsafe_ai_logo.png`).

Regenerate launcher icons after logo updates:

```bash
dart run flutter_launcher_icons
```
